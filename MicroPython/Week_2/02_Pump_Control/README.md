## หลักการทางเคมี (Chemistry Principles)

### ทำไมต้องสอบเทียบปั๊ม?

ในการไทเทรตอัตโนมัติ ปริมาตรสารไทแทรนต์ต้องแม่นยำมาก:

| ผลกระทบ | รายละเอียด |
|---------|-----------|
| ความผิดพลาด 0.1 mL | อาจทำให้คำนวณความเข้มข้นผิดพลาด 1-2% |
| Flow rate ไม่แน่นอน | หาจุดสมมูล (equivalence point) ได้ยาก |
| ปั๊มแต่ละตัว | มี flow rate ไม่เท่ากัน - ต้องสอบเทียบทุกครั้ง |

### สูตรคำนวณ

```
Flow Rate (mL/s) = ปริมาตรที่วัดได้ (mL) / เวลา (s)
```

**ตัวอย่าง:**
- ปั๊ม 15 วินาที ได้ปริมาตร 4.2 mL
- Flow Rate = 4.2 / 15 = 0.28 mL/s

### การประเมินความสม่ำเสมอด้วย %RSD

```
%RSD = (Standard Deviation / Average) x 100
```

| %RSD | ความหมาย | สถานะ |
|:----:|----------|:-----:|
| < 2% | ดีเยี่ยม | ผ่าน |
| 2-5% | พอใช้ได้ | ผ่าน |
| >= 5% | ไม่สม่ำเสมอ | ต้องตรวจสอบ |

**โค้ดสำคัญ - การคำนวณ Flow Rate และ %RSD:**

```python
def record_measurement():
    """
    บันทึกผลการวัดและคำนวณ flow rate
    สูตร: flow_rate = volume / time (mL/s)
    """
    global calibration_data, current_volume

    # ใช้ค่าจากตัวแปร MEASURED_VOLUME
    current_volume = MEASURED_VOLUME

    # คำนวณ flow rate
    flow_rate = current_volume / elapsed_time

    # บันทึกข้อมูล
    calibration_data.append((elapsed_time, current_volume, flow_rate))

    # คำนวณค่าเฉลี่ยและ RSD
    if len(calibration_data) >= 2:
        avg_flow_rate = sum(d[2] for d in calibration_data) / len(calibration_data)
        variance = sum((d[2] - avg_flow_rate) ** 2 for d in calibration_data) / len(calibration_data)
        std_dev = variance ** 0.5
        rsd = (std_dev / avg_flow_rate) * 100  # %RSD

        if rsd > 5:
            print("*** คำเตือน: RSD > 5% - ค่าไม่สม่ำเสมอ ***")
```

## เคล็ดลับการปฏิบัติ (Practical Tips)

### การเตรียมอุปกรณ์

1. ใช้กระบอกตวงที่มีความละเอียด 0.1 mL หรือดีกว่า
2. ตรวจสอบว่าท่อปั๊มไม่มีฟองอากาศ (purge ก่อนสอบเทียบ)
3. วางกระบอกตวงให้ตั้งตรง

### การวัด Flow Rate

1. ทำซ้ำ 3-5 ครั้งเพื่อหาค่าเฉลี่ย
2. ปั๊มครั้งละ 10-20 วินาทีเพื่อให้ได้ปริมาตรที่วัดง่าย
3. อ่านกระบอกตวงที่ระดับสายตา (meniscus)

### การแก้ไขเมื่อ %RSD >= 5%

| สาเหตุที่เป็นไปได้ | วิธีแก้ไข |
|-------------------|----------|
| ฟองอากาศในท่อ | Purge ท่อ (ปั๊มจนไม่มีฟอง) |
| ท่อหลวม | ตรวจสอบการเชื่อมต่อท่อ |
| แหล่งจ่ายไฟไม่เสถียร | ใช้แหล่งจ่ายไฟคุณภาพดี |
| จำนวนครั้งน้อย | เพิ่มจำนวนครั้งในการวัด |

## GPIO Configuration

| อุปกรณ์ | GPIO | ค่าคงที่ | ประเภท | หมายเหตุ |
|---------|:----:|---------|--------|----------|
| Pump | 21 | `PUMP_PIN` | PWM Output | freq=1000 Hz |
| Red LED (ปั๊มทำงาน) | 2 | `LED_RED` | Output | แสดงสถานะปั๊ม |
| Green LED (บันทึกสำเร็จ) | 4 | `LED_GREEN` | Output | แสดงการบันทึก |
| Button 1 (Start/Stop) | 34 | `BUTTON1` | Input-only | External pull-down |
| Button 2 (Record) | 35 | `BUTTON2` | Input-only | External pull-down |
| Button 3 (Save) | 39 | `BUTTON3` | Input-only | External pull-down |

### PWM Settings

```python
# ความถี่ 1000 Hz, Duty Cycle 10-bit (0-1023)
pump_pwm = PWM(Pin(21), freq=1000)
pump_pwm.duty(1023)  # Full speed
pump_pwm.duty(0)     # Stop
```

**การเชื่อมโยง Duty Cycle กับ Flow Rate:**

| Duty Cycle | ค่า | ความเร็วปั๊ม |
|:----------:|:---:|:------------:|
| 100% | 1023 | เต็มกำลัง |
| 50% | 511 | ครึ่งกำลัง |
| 0% | 0 | หยุด |
