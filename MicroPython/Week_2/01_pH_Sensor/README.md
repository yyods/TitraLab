## หลักการทางเคมี (Chemistry Principles)

### สมการ Nernst

หัววัด pH ให้สัญญาณแรงดันไฟฟ้า (mV) ตามสมการ:

```
E = E0 - (2.303RT/nF) x pH
```

จัดรูปใหม่เป็นสมการเส้นตรง:

```
E (mV) = m x pH + b
```

| ตัวแปร | ความหมาย | ค่าทฤษฎีที่ 25C |
|--------|----------|----------------|
| m (slope) | ความชัน | -59.16 mV/pH |
| b (intercept) | ศักย์ไฟฟ้าที่ pH=0 | ขึ้นกับหัววัด |

### ความชัน Nernst ที่อุณหภูมิต่างๆ

| อุณหภูมิ (C) | อุณหภูมิ (K) | ความชันทฤษฎี (mV/pH) |
|:------------:|:------------:|:--------------------:|
| 20 | 293.15 | -58.17 |
| **25** | **298.15** | **-59.16** |
| 30 | 303.15 | -60.15 |

### การสอบเทียบ 3 จุด

| สารละลายบัฟเฟอร์ | ค่า pH | ความสำคัญ |
|:----------------:|:------:|-----------|
| Potassium hydrogen phthalate | 4.00 | ตัวแทนช่วงกรด (acidic range) |
| Phosphate buffer | 7.00 | จุด isopotential - ไม่ขึ้นกับอุณหภูมิ |
| Carbonate-bicarbonate buffer | 10.00 | ตัวแทนช่วงเบส (basic range) |

**ผลลัพธ์:**
- ไฟล์ `data_calibrate.txt` ที่มี slope, intercept, R-squared, อุณหภูมิ
- ไฟล์ `calibration_log.txt` รายละเอียดการสอบเทียบ

**เกณฑ์ความสำเร็จ:**

| ตัวชี้วัด | ดีเยี่ยม | พอใช้ได้ | ต้องทำใหม่ |
|----------|:--------:|:--------:|:---------:|
| R-squared | >= 0.999 | >= 0.99 | < 0.99 |
| Slope Efficiency | 95-105% | 90-110% | นอกช่วงนี้ |

**โค้ดสำคัญ - การคำนวณ Linear Regression:**

```python
def linear_regression(x_values, y_values):
    """
    คำนวณการถดถอยเชิงเส้น y = mx + b พร้อมค่า R-squared
    สำหรับเซ็นเซอร์ pH: E(mV) = m * pH + b
    """
    n = len(x_values)

    # คำนวณค่าที่ต้องใช้ (Calculate required sums)
    sum_x = sum(x_values)
    sum_y = sum(y_values)
    sum_xy = sum(x * y for x, y in zip(x_values, y_values))
    sum_x2 = sum(x ** 2 for x in x_values)

    # คำนวณความชัน (Calculate slope)
    denominator = n * sum_x2 - sum_x ** 2
    slope = (n * sum_xy - sum_x * sum_y) / denominator

    # คำนวณจุดตัดแกน y (Calculate intercept)
    intercept = (sum_y - slope * sum_x) / n

    # คำนวณ R-squared
    y_mean = sum_y / n
    ss_tot = sum((y - y_mean) ** 2 for y in y_values)
    ss_res = sum((y - (slope * x + intercept)) ** 2
                 for x, y in zip(x_values, y_values))
    r_squared = 1 - (ss_res / ss_tot)

    return slope, intercept, r_squared
```

## เคล็ดลับการปฏิบัติ (Practical Tips)

### การเตรียมสารละลายบัฟเฟอร์

1. ใช้สารละลายบัฟเฟอร์มาตรฐานที่ยังไม่หมดอายุ
2. เก็บรักษาในภาชนะที่ปิดสนิท ห่างจากความร้อนและแสง
3. ตรวจสอบอุณหภูมิของสารละลายบัฟเฟอร์

### การล้างหัววัด

1. ล้างด้วยน้ำกลั่น (deionized water) ระหว่างเปลี่ยนบัฟเฟอร์
2. ซับน้ำเบาๆ ด้วยกระดาษทิชชู่ - ห้ามถูแรง
3. ไม่ควรปล่อยให้หัววัดแห้ง

### เวลารอให้ค่าเสถียร (Stabilization Time)

- รอ 30-60 วินาทีหลังจากแช่หัววัดในบัฟเฟอร์
- ค่าควรเปลี่ยนแปลงน้อยกว่า 1 mV/นาที ก่อนกดบันทึก

### การแก้ไขเมื่อ R-squared < 0.99

| สาเหตุที่เป็นไปได้ | วิธีแก้ไข |
|-------------------|----------|
| สารละลายบัฟเฟอร์เสื่อมสภาพ | ใช้บัฟเฟอร์ใหม่ |
| หัววัดสกปรก | ทำความสะอาดหัววัด |
| สายสัญญาณหลวม | ตรวจสอบการเชื่อมต่อ |
| ไม่รอให้เสถียร | รอนานขึ้นก่อนกดบันทึก |
