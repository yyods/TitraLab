# Blocks ตัวอย่างที่ 1: อ่านอุณหภูมิ DS18B20 แสดงบนจอ TFT
# Blocks Example 1: DS18B20 Temperature on the TFT Display

ตัวอย่างนี้ประกอบโปรแกรมในหน้า **Blocks** ของแอป SciLabPro MicroPad:
อ่านอุณหภูมิจากเซ็นเซอร์ DS18B20 ทุก 1 วินาที แสดงทั้งใน Console และบนจอ TFT ของบอร์ด

This example builds a program on the app's **Blocks** page: read the DS18B20
temperature every second and show it in the Console **and** on the board's TFT.

## เตรียมฮาร์ดแวร์ (Hardware setup)

| รายการ | ค่า |
| --- | --- |
| เซ็นเซอร์ | DS18B20 (สาย 1-Wire) |
| ขา GPIO | **GPIO16** (ต่อผ่าน jumper ตามผังบอร์ด — ดู `Week_1/pins.py`) |
| Pull-up | ตัวต้านทาน **4.7 kΩ** ระหว่างสาย DATA กับ 3.3 V (จำเป็น!) |
| เฟิร์มแวร์ | 0.4.17 ขึ้นไป |

## ประกอบบล็อก (Assemble the blocks)

ลากบล็อกต่อกันจากบนลงล่างตามลำดับนี้ (หมวด → ชื่อบล็อก):

**Drag these blocks in order (category → block):**

1. **Advanced → Raw Python** — พิมพ์โค้ดเตรียมจอ (ทำครั้งเดียวก่อนลูป):

```python
import gc
gc.collect()
from machine import Pin, SPI
from ili9341 import Display, color565
from xglcd_font import XglcdFont
slp.release_tft()
spi = SPI(1, baudrate=40000000, sck=Pin(14), mosi=Pin(13))
display = Display(spi, dc=Pin(27), cs=Pin(15), rst=Pin(0),
                  width=320, height=240, rotation=90)
font = XglcdFont('fonts/EspressoDolce18x24.c', 18, 24)
display.clear(color565(0, 0, 0), hlines=2)
display.draw_text(20, 20, 'DS18B20 Temperature', font, color565(0, 255, 255))
```

2. **Control → Forever** — ลูปตลอดไป (มี stop check ให้อัตโนมัติ) แล้ววางบล็อกข้อ 3–6 **ข้างใน**:

3. **Basics → Set variable** ตั้งชื่อตัวแปร `temp` = **Devices → Read DS18B20 (°C)** on pin **16**

4. **Console → Print value** — พิมพ์ค่า `temp`

5. **Advanced → Raw Python** — แสดงค่าบนจอ (วาดทับค่าเดิม):

```python
display.fill_rectangle(20, 70, 280, 30, color565(0, 0, 0))
display.draw_text(20, 72, 'T = {:.1f} C'.format(temp), font,
                  color565(255, 255, 0))
```

6. **Timing → Sleep s** — หน่วง **1** วินาที

กด **Run** — Console จะแสดงตัวเลขทุกวินาที และจอ TFT แสดง `T = 25.3 C` (ค่าจริงของห้อง)

## แก้ปัญหา (Troubleshooting)

| อาการ | สาเหตุ / วิธีแก้ |
| --- | --- |
| `OSError: no DS18B20 found on pin 16` | เซ็นเซอร์ไม่ได้ต่อที่ GPIO16 หรือไม่มี pull-up 4.7 kΩ — ตรวจ jumper และตัวต้านทาน |
| ค่าอ่านช้า ~750 ms | ปกติของ DS18B20 (เวลาแปลงสัญญาณของเซ็นเซอร์เอง) |
| จอไม่แสดงผล | ตรวจว่าใส่บล็อก Raw Python ข้อ 1 ไว้ **ก่อน** บล็อก Forever (นอกลูป) |
| ค่าซ้อนกันบนจอ | ต้องมีบรรทัด `fill_rectangle` (ลบค่าเดิม) ก่อน `draw_text` เสมอ |

## แนวคิดที่ได้เรียนรู้ (What you learned)

- บล็อก **Read DS18B20** คืนค่าเป็นตัวเลข → เก็บในตัวแปรแล้วส่งต่อให้บล็อกอื่นได้
- บล็อก **Raw Python** คือสะพานจาก Blocks ไปสู่โค้ด Python จริง — เมื่อบล็อกสำเร็จรูปยังไม่มี
  ความสามารถที่ต้องการ (เช่น จอ TFT) เราเขียน Python แทรกเองได้
- จอ TFT ต้อง **เตรียมครั้งเดียว** นอกลูป และ **ลบค่าเดิมก่อนวาดใหม่** ในลูป
