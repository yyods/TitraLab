# Blocks ตัวอย่างที่ 1: อ่านอุณหภูมิ DS18B20 แสดงบนจอ TFT
# Blocks Example 1: DS18B20 Temperature on the TFT Display

ตัวอย่างนี้อยู่ในแอป SciLabPro MicroPad: หน้า **Blocks → Examples →
"DS18B20 Temperature on TFT"** — กดโหลดแล้วบล็อกทั้ง 5 ชิ้นจะปรากฏบนพื้นที่ทำงาน
พร้อมรันทันที ไม่ต้องประกอบเอง ไม่ต้องเขียนโค้ดเลย (เหมาะกับนักเรียนประถม!)

This example ships inside the app: **Blocks → Examples → "DS18B20 Temperature
on TFT"** — tap Load and the 5 blocks appear on the canvas ready to run.
No assembly, no code writing (primary-school friendly!).

## เตรียมฮาร์ดแวร์ (Hardware setup)

| รายการ | ค่า |
| --- | --- |
| เซ็นเซอร์ | DS18B20 (สาย 1-Wire) |
| ขา GPIO | **GPIO16** (ต่อผ่าน jumper ตามผังบอร์ด — ดู `Week_1/pins.py`) |
| Pull-up | ตัวต้านทาน **4.7 kΩ** ระหว่างสาย DATA กับ 3.3 V (จำเป็น!) |
| จอ TFT | ติดตั้งบนบอร์ดอยู่แล้ว — ไม่ต้องต่ออะไรเพิ่ม |
| แอป / เฟิร์มแวร์ | MicroPad 1.3.1 (40) ขึ้นไป / เฟิร์มแวร์ 0.4.17 ขึ้นไป |

## บล็อกทั้ง 5 ชิ้น (The 5 blocks)

1. **แสดงข้อความบนจอ** "DS18B20 Temperature" แถวที่ **1** (Show text on screen, row 1)
2. **ทำซ้ำตลอดไป** (Forever) — วางข้อ 3–5 ข้างใน:
3. ตั้งตัวแปร `temp` = **อ่าน DS18B20 (°C)** ขา **16**
4. **พิมพ์ค่า** `temp` (Print value — แสดงใน Console ด้วย)
5. **แสดงค่าบนจอ** `temp` แถวที่ **3** แล้ว **หน่วง 1 วินาที** (Sleep 1 s)

จอ TFT เป็นอุปกรณ์ติดบอร์ด (fixed hardware) — บล็อกจอจึงไม่ต้องตั้งค่าใด ๆ
เลือกได้แค่ "แถวที่ 1–6" ผิดไม่ได้เลย

## โค้ดที่บล็อกสร้างให้ (The generated Python)

ดู [`01_ds18b20_tft_reference.py`](01_ds18b20_tft_reference.py) — โค้ดจริงที่บล็อกสร้าง
(ตรวจสอบบนบอร์ดจริงแล้ว: อ่านได้ 25.9–26.0 °C พร้อมแสดงบนจอ) การเตรียมจอ
(SPI, ฟอนต์, การลบค่าเดิมก่อนวาด) ระบบสร้างให้อัตโนมัติเมื่อมีบล็อกจอ —
นักเรียนไม่ต้องเห็นหรือเข้าใจส่วนนี้ก่อนวัยอันควร

See [`01_ds18b20_tft_reference.py`](01_ds18b20_tft_reference.py) — bench-verified
on the real board (25.9–26.0 °C live). The display setup (SPI, font,
erase-before-redraw) is generated automatically whenever a screen block is
present — students never need to see it.

## แก้ปัญหา (Troubleshooting)

| อาการ | สาเหตุ / วิธีแก้ |
| --- | --- |
| `OSError: no DS18B20 found on pin 16` | เซ็นเซอร์ไม่ได้ต่อที่ GPIO16 หรือไม่มี pull-up 4.7 kΩ |
| ค่าอ่านช้า ~750 ms | ปกติของ DS18B20 (เวลาแปลงสัญญาณของเซ็นเซอร์) |
| ตัวเลขบนจอกระพริบเล็กน้อยทุกวินาที | ปกติ — คือจังหวะลบค่าเดิมก่อนวาดค่าใหม่ |
