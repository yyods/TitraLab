## DAC คืออะไร? (What is DAC?)

**DAC (Digital-to-Analog Converter)** แปลงค่าดิจิทัลเป็นแรงดันไฟฟ้าแบบแอนะล็อก

DAC converts digital values to analog voltage.

### เปรียบเทียบ ADC vs DAC (Comparison)

| ทิศทาง (Direction) | ตัวแปลง (Converter) | อินพุต (Input) | เอาต์พุต (Output) |
|-------------------|---------------------|----------------|-------------------|
| แอนะล็อก -> ดิจิทัล | ADC | แรงดัน 0-3.3V | ค่า 0-4095 (12-bit) |
| ดิจิทัล -> แอนะล็อก | DAC | ค่า 0-255 (8-bit) | แรงดัน 0-3.3V |

### สูตรคำนวณ DAC (DAC Calculation Formula)

```
Voltage = (DAC_value / 255) * 3.3V
```

| ค่า DAC | แรงดัน (Voltage) |
|---------|------------------|
| 0       | 0.00 V           |
| 64      | 0.83 V           |
| 128     | 1.65 V           |
| 192     | 2.48 V           |
| 255     | 3.30 V           |

## ESP32 DAC Channels

ESP32 มี DAC 2 ช่อง (ESP32 has 2 DAC channels):

| ช่อง (Channel) | GPIO | การใช้งานในบอร์ด TitraLab |
|----------------|------|---------------------------|
| DAC1 | GPIO25 | pH Sensor (PH_PIN) |
| DAC2 | GPIO26 | Buzzer (BUZZER_PIN) |

**ในตัวอย่างนี้ใช้ GPIO26** เพื่อหลีกเลี่ยงการรบกวนเซ็นเซอร์ pH

**This example uses GPIO26** to avoid interfering with the pH sensor.

## 02_dac_waveform.py - สร้างคลื่นสัญญาณ

### ชนิดคลื่นที่สร้างได้ (Waveform types)

1. **คลื่นฟันเลื่อย (Sawtooth)** - แรงดันเพิ่มเป็นเส้นตรงแล้วตกลงทันที
2. **คลื่นสามเหลี่ยม (Triangle)** - แรงดันเพิ่มขึ้นแล้วลดลงอย่างสม่ำเสมอ
3. **คลื่นไซน์ (Sine)** - คลื่นรูปไซน์
4. **คลื่นขั้นบันได (Staircase)** - แรงดันเพิ่มขึ้นเป็นขั้นๆ

### วิธีดูคลื่นสัญญาณ (How to view waveform)

**วิธีที่ 1: ใช้ Oscilloscope (แนะนำ)**
- ต่อ probe ที่ GPIO26 และ GND
- ตั้งค่า Time division ประมาณ 500ms/div
- ตั้งค่า Voltage division ประมาณ 1V/div

**วิธีที่ 2: ใช้ LED + Resistor**
- ต่อ LED (+ resistor 330 ohm) ระหว่าง GPIO26 และ GND
- LED จะค่อยๆ สว่างขึ้น-มืดลง ตามแรงดัน
- เหมาะสำหรับคลื่นความถี่ต่ำ (< 10 Hz)

## ความเชื่อมโยงกับเคมี (Chemistry Connections)

DAC มีการใช้งานในอุปกรณ์วิเคราะห์เคมีหลายประเภท:

| การใช้งาน | คำอธิบาย |
|-----------|----------|
| สร้างสัญญาณกระตุ้น | ใช้ใน Cyclic Voltammetry (CV) เพื่อกวาดศักย์ไฟฟ้า |
| สัญญาณอ้างอิง | สร้างแรงดันอ้างอิงสำหรับการสอบเทียบเซ็นเซอร์ |
| ควบคุมอุปกรณ์ | ควบคุมความเข้มแสงของหลอดไฟใน Spectrophotometer |
| ทดสอบระบบ | ทดสอบความเป็นเส้นตรงของ ADC หรือ Amplifier |

**หมายเหตุ:** ในระบบ TitraLab ไม่ได้ใช้ DAC โดยตรงในการไทเทรชัน แต่ความรู้เรื่อง DAC ช่วยให้เข้าใจหลักการทำงานของอุปกรณ์วิเคราะห์อื่นๆ

## ตัวอย่างโค้ดพื้นฐาน (Basic Code Example)

```python
from machine import DAC, Pin

# สร้าง DAC object (Create DAC object)
dac = DAC(Pin(26))

# กำหนดค่า DAC 0-255 (Set DAC value 0-255)
dac.write(0)    # 0V
dac.write(128)  # 1.65V (ประมาณ)
dac.write(255)  # 3.3V
```

## ข้อจำกัดของ ESP32 DAC (ESP32 DAC Limitations)

1. **Resolution 8-bit เท่านั้น** - ค่า 0-255 เท่านั้น (ความละเอียดต่ำกว่า ADC ที่เป็น 12-bit)
2. **ความเร็วจำกัด** - ไม่เหมาะกับสัญญาณความถี่สูง (> 100 Hz)
3. **มีเพียง 2 ช่อง** - GPIO25 และ GPIO26 เท่านั้น
4. **แรงดันขาออกมีข้อจำกัด** - อาจไม่เป็นเส้นตรงที่ค่าต่ำมากหรือสูงมาก

## การแก้ไขปัญหาที่พบบ่อย (Troubleshooting)

### ปัญหา: แรงดันไม่ตรงกับค่าทฤษฎี

**สาเหตุ:**
- ความคลาดเคลื่อนของ DAC ภายใน ESP32
- โหลดที่ต่อกับขา DAC ดึงกระแสมากเกินไป

**วิธีแก้:**
- ใช้ Buffer amplifier (Op-amp) ถ้าต้องการความแม่นยำสูง
- หลีกเลี่ยงการต่อโหลดที่มี impedance ต่ำ

### ปัญหา: ไม่มีสัญญาณออก

**ตรวจสอบ:**
1. ใช้ขา GPIO25 หรือ GPIO26 เท่านั้น
2. ไม่ได้ใช้ขานั้นเป็น GPIO output พร้อมกัน
3. Multimeter ตั้งเป็นโหมด DC Voltage
