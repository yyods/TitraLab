# คู่มืออ้างอิงฉบับย่อ (Quick Reference Card)

---

## เลือกโหมดตามงานที่ต้องทำ (Select Mode by Task)

| งานที่ต้องทำ | โหมด | ปุ่มกด |
|-------------|------|--------|
| **ก่อนเริ่มทดลอง**: สอบเทียบ pH | Mode 1: Calibrate pH | กด 1 จากเมนูหลัก |
| **ก่อนเริ่มทดลอง**: สอบเทียบปั๊ม | Mode 3: Calibrate Flow | กด 3 จากเมนูหลัก |
| ตรวจสอบค่า pH ปัจจุบัน | Mode 2: pH Test | กด 2 จากเมนูหลัก |
| ทดสอบปั๊ม | Mode 4: Flow Test | กด 4 จากเมนูหลัก |
| ล้างท่อก่อน/หลังทดลอง | Mode 5: Purge | กด 5 จากเมนูหลัก |
| **ทำการไทเทรชัน** | Mode 6: Titration | กด 6 จากเมนูหลัก |

---

## ลำดับการใช้งานในวันทดลอง

```
วันทดลอง (Lab Day)

1. [Mode 5: Purge]       ล้างท่อด้วยน้ำกลั่น (2-3 นาที)
         │
         ▼
2. [Mode 1: Calibrate pH] สอบเทียบด้วย buffer pH 4, 7, 10
         │                 (ต้องได้ R² >= 0.99)
         ▼
3. [Mode 3: Calibrate Flow] สอบเทียบอัตราไหลปั๊ม
         │                   (ต้องได้ %RSD < 5%)
         ▼
4. [Mode 6: Titration]    ทำการไทเทรชัน
         │                 (รอจนถึงจุดสมมูล)
         ▼
5. [Mode 5: Purge]        ล้างท่อหลังเสร็จ
```

## ถ้าเกิดปัญหา (Troubleshooting)

| ปัญหา | วิธีแก้ |
|-------|-------|
| R² < 0.99 | ล้าง pH probe, ใช้ buffer ใหม่ |
| ค่า pH อ่านไม่ได้ | ตรวจสอบการต่อสาย GPIO25 |
| ปั๊มไม่ทำงาน | ตรวจสอบ GPIO21, ท่อปั๊มอุดตัน? |
| ไฟล์ไม่พบ | ตรวจสอบ ESP32 flash ผ่าน Thonny |
| จอไม่แสดงผล | กดปุ่ม Reset |
